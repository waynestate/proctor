# PROCTOR brand files

**The mark is the proctor's eye:** an eye with a square gold pupil, on the green tile. It watches the exam and doesn't help.

## Origin
The mark is generated by ChatGPT. Nobody draws or edits the mark's geometry. The PNGs in this folder are the brand.
If a vector is ever needed, trace the PNG with [vtracer](https://github.com/vtracer/vtracer) or
[potrace](https://potrace.sourceforge.net/); do not redraw it.

## Colours
| Role | Colour |
|---|---|
| Tile | Wayne State green `#0C5449` |
| Pupil (the only gold) | Wayne State gold `#FFCC33` |
| Site background | Cream `#F4F1EA` |
| Site accent only, never in the mark | Crimson `#9B1C2E` (the red pen) |

Gold never sits behind white text.

## The board
`proctor-board.png` is the full brand board: the hero mark, the app icon, the horizontal and stacked lockups, the mark
on light and dark backgrounds, the colour palette, the type (Lato Black for headings, Lato Regular for body), the
favicons, the clear space (one gold pupil height on every side), the do's and don'ts, and a product usage example.

## Rules
- Use the approved mark and keep its proportions.
- Don't recolour it, stretch it, or add effects.
- Don't redraw or edit the mark's geometry. If a vector is ever needed, trace the PNG with vtracer or potrace.
